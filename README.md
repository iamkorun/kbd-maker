# KBD Maker

Type a keyboard shortcut (e.g. `Ctrl + V`, `Ctrl + Left Click`), then copy it as a PNG image and paste it into Canva, Slides or anywhere else.

พิมพ์คีย์ลัดที่ต้องการ (เช่น `Ctrl + V`, `Ctrl + Left Click`) แล้วกด Copy เพื่อนำรูปปุ่มไปวางใน Canva, Slides หรือที่ไหนก็ได้

**Live:** https://iamkorun.github.io/kbd-maker/

- Light / Dark / Flat / Outline styles
- Mac symbols (⌘ ⌥ ⇧), mouse clicks and scroll
- Copy to clipboard or download PNG
- English / ไทย
